# 本地启动指南（已实测可运行）

> 最后验证：2026-10-17，Windows + VirtualBox 虚拟机 `studybox`(Ubuntu 22.10) + JDK 17 + Ollama

## 0. 架构与端口

```
Windows 宿主
├── 前端 Vite            http://localhost:5173
├── 后端 Spring Boot     http://localhost:8080
├── Ollama               127.0.0.1:11434   (qwen2.5-coder:7b)
└── VirtualBox 虚拟机 studybox (Ubuntu 22.10)
    ├── MySQL   guest 3306  ── NAT 转发 ──> 宿主 13306
    ├── Redis   guest 6379  ── NAT 转发 ──> 宿主 16379
    ├── SSH     guest 22    ── NAT 转发 ──> 宿主 2222
    └── nginx   guest 80    ── NAT 转发 ──> 宿主 8082
```

`application.properties` 里默认的 **MySQL 13306 / Redis 16379** 就是这台虚拟机的 NAT 转发端口，不需要改。
`src/main/resources/application-local.properties`（已在 .gitignore 中，不提交）只保存密码：

```properties
spring.data.redis.password=qw928826
spring.datasource.password=1234
```

## 1. 启动虚拟机（必须先启动）

图形界面：VirtualBox → 选中 `studybox` → 启动。

或命令行（headless，不开窗口）：

```bash
"C:/Program Files/Oracle/VirtualBox/VBoxManage.exe" startvm studybox --type headless
```

等 30~60 秒（Ubuntu 启动 + MySQL/Redis 自启），确认端口可用：

```bash
mysql --connect-timeout=5 -h 127.0.0.1 -P 13306 -uroot -p1234 -e "SELECT 1"
```

Redis 验证（在虚拟机里执行，或 Windows 上用任意 redis 客户端连 `127.0.0.1:16379`，密码 `qw928826`）：

```bash
redis-cli -a qw928826 ping     # 期望 PONG
```

## 2. 初始化数据库（仅首次）

```bash
mysql -h 127.0.0.1 -P 13306 -uroot -p1234 < docs/schema.sql
```

脚本用的是 `CREATE ... IF NOT EXISTS`，已有 `aichat` 库和 `tb_user` 表时不会动数据。

## 3. 确认 Ollama

```bash
ollama list        # 需要 qwen2.5-coder:7b
```

## 4. 启动后端

```bash
cd D:/maven-project/aichat
mvn -DskipTests package
java -Dfile.encoding=UTF-8 -Dsun.stdout.encoding=UTF-8 \
  -jar target/aichat-0.0.1-SNAPSHOT.jar
```

- 端口 `8080`，日志出现 `Started AichatApplication` 即成功
- 未接短信服务，验证码打印在日志中：

```
WARN ... [DEV] 未接入短信服务，验证码仅打印在日志: phone=13800138000, code=258424
```

> 修改 `application-local.properties` 后必须重新 `mvn package`，否则 jar 里还是旧配置。

## 5. 启动前端

```bash
cd D:/桌面/Vue/ai-chat-project
npm install        # 仅首次
npm run dev        # http://localhost:5173
```

`/api` 由 Vite 代理到 `.env.development` 的 `VITE_API_BASE_URL=http://localhost:8080`。

## 6. 验证流程

1. 打开 `http://localhost:5173`（用 localhost，不要用 127.0.0.1）→ 跳到登录页
2. 输入手机号 → 「发送验证码」→ 到后端日志找 `code=`
3. 输入验证码登录；新用户会进入「设置密码」（需等 60 秒冷却后重新获取验证码）
4. 进入聊天页发消息，即可看到 Ollama 流式回复

## 7. 关闭

```bash
# 后端 / 前端：Ctrl+C 或关闭对应终端
# 虚拟机关机（宿主执行，等同按电源键）
"C:/Program Files/Oracle/VirtualBox/VBoxManage.exe" controlvm studybox acpipowerbutton
```

## 8. 常见问题

| 现象 | 原因 / 处理 |
|------|-------------|
| `Communications link failure` / Redis 连接失败 | 虚拟机没启动，或内部的 MySQL/Redis 没起来 |
| `Access denied for user 'root'` | 虚拟机里的 MySQL 密码不是 `1234` |
| 启动 VM 报端口占用 | 13306/16379 被别的程序占着（比如另开的 MySQL/Redis），先关掉占用进程 |
| 前端接口 502 | 后端没启动，或不在 8080 |
| 验证码错误/已过期 | 5 分钟有效、一次性；同一手机号 60 秒冷却 |
| 日志中文乱码 | 启动加 `-Dfile.encoding=UTF-8 -Dsun.stdout.encoding=UTF-8` |
| 首次回复很慢 | Ollama 首次加载 7B 模型需要几十秒 |

> 聊天记录目前只存 Redis（7 天 TTL），超过期限会丢；持久化方案见 `BACKEND_TODO.md` P1#1。
