## 六、文档维护约定

1. **一个事实只有一个出处**：阶段定义在设计文档 §11，排期在 `路线图.md`，别在 README 里再抄一份。
2. **过期就归档，不删**：移到 `archive/`，并在被取代的文档顶部写一行指针。
3. **加文档先问**：能否并入现有文档？能并就不新建。
4. 每次改完代码顺手更新对应章节，别攒到最后一起"整理文档"。
