## 三、维护约定

1. **一个主题一份文档**。出现“v2 / 新版 / 最终版”就说明这里没合并——直接改原文件，旧的删掉（git 里有历史）。
2. **改代码同时改文档**：表结构变了改 `schema.sql` + 加迁移；行为变了改对应设计文档的“现在是什么样”。
3. **不在文档里贴大段代码**，贴类名 + 行号 + 一句话结论。
4. **删文档不心疼**：`git log --diff-filter=D --name-only` 能找到；确认真的没用了就删，留着才是负担。
